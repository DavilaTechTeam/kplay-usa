# KPLAY USA Demo Website

A responsive static demo site for KPLAY USA.

## Included
- Responsive homepage
- About section with "Established in 2023"
- Services
- Concept portfolio layout
- Four-step process
- Contact form UI
- Mobile navigation
- Scroll reveal effects
- SEO title and description

## Preview
Open `index.html` in a browser.

For best results, run a local server:
```bash
python3 -m http.server 8000
```
Then visit:
http://localhost:8000

## GitHub Pages deployment
1. Create a GitHub repository.
2. Upload `index.html`, `styles.css`, and `script.js` to the repository root.
3. In GitHub: Settings → Pages.
4. Deploy from the `main` branch and root folder.
5. Add the client's custom domain when ready.

## Before production launch
- Replace concept portfolio art with KPLAY USA's real project photos.
- Confirm actual business email, phone number, and mailing address.
- Connect the contact form to the client's email/CRM/Formspree/HubSpot.
- Add real social links.
- Add Privacy Policy / Terms if needed.
- Confirm project/client names before publishing any logos or case studies.
